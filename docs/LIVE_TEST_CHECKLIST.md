# Чек-лист боевого прогона

Приёмочная проверка `wordstat collect` против живого Wordstat через Chrome (CDP).
Юнит-тесты покрывают только чистые слои (`storage`, `csv_io`, `dtypes`,
`dataset_io`); `collector.py` проверяется вручную — этот чек-лист и есть
процедура. Дата-независим: границы окон динамики вычисляйте от сегодняшнего дня.

## Предусловия

- Chrome запущен с `--remote-debugging-port=9223
  --user-data-dir=$HOME/wordstat-chrome-profile` и авторизован в Яндексе
  (проверка: `curl -s http://127.0.0.1:9223/json/version` отвечает JSON).
- Нет параллельных прогонов: одна `BrowserSession` — один прогон, две сессии
  в одном Chrome будут мешать друг другу.
- `pytest` и `ruff check .` зелёные (офлайн-фундамент).

Пример условия для всех пунктов: после каждого прогона проверяются код выхода
(`echo $?`), содержимое run-каталога и `manifest.json`.

## A. Валидация без браузера (fail-fast, Chrome не стартует)

| # | Команда (суть) | Ожидание |
|---|---|---|
| A1 | `wordstat collect` (0 фраз) | exit 1, `At least one search phrase is required` |
| A2 | фраза из пробелов | exit 1, `The search phrase must not be empty` |
| A3 | `--region " "` | exit 1, `The region must not be empty` |
| A4 | даты: одна граница / реверс / `2024-02-30` / `<2018-01-01` / daily >60 дней или в будущем / weekly <3 недель / monthly <3 месяцев | exit 1, тексты из `periods.py` |
| A5 | `--granularity bogus` | exit 2 (usage-ошибка click) |
| A6 | несуществующий `--phrases-file` | exit 2 |
| A7 | несуществующий `--resume-dir` | exit 2 |
| A8 | `--resume-dir` + 2 фразы | exit 1, `requires exactly one phrase` |
| A9 | phrases-file с недекодируемыми байтами | exit 1, `Cannot decode` |

## B. Живые прогоны (happy path)

- **B1. Дефолты** (`wordstat collect "<фраза>"`): exit 0; stdout — путь
  `manifest.json`; 4 parquet; stderr — `Собрано 1 из 1, из них частично 1`
  и две строки `пустой экспорт (0 строк)` (top-виды, штатно); dynamics/regions
  с строками > 0 и dtypes int64/float64 у числовых колонок; в манифесте
  `status: incomplete`, `requested_period: null`.
- **B2. Повторный прогон той же фразы**: новый run-каталог, старый нетронут.
  Суффикс коллизии `-2` живым прогоном недостижим (прогоны дольше секунды —
  таймстампы различаются); покрыт юнит-тестом `test_storage.py`.
- **B3. `--keep-raw`**: рядом с parquet лежат 4 `<view>.csv`; CSV — UTF-8 с
  BOM, разделитель `;`, терминатор строк одиночный CR; в манифесте `raw_file`
  заполнены.
- **B4. `--granularity daily` + окно ≤60 дней, не будущее**: файл
  `dynamics_daily.parquet`, строки `Период` формата `DD.MM.YYYY`,
  `requested_period`/`actual_period` записаны. Последний день у present-края
  может отсутствовать (лаг данных Яндекса) — это не ошибка.
- **B5. `--granularity weekly` + окно ≥3 полных недель (старт — понедельник)**:
  окно применяется (проверено живым прогоном 01.09.2026 — вопреки старой
  пометке README). Последняя неделя у present-края может отсутствовать (лаг).
- **B6. `--granularity monthly` + окно ≥3 месяцев**: `dynamics.parquet`,
  фактические месяцы = запрошенным (у present-края последний месяц может
  отсутствовать — август отсутствовал 01.09.2026; историческое окно даёт
  ровно запрошенные месяцы).
- **B7. Батч**: несколько PHRASE + `--phrases-file` (UTF-8 с BOM, краевые
  пробелы, дубль фразы — дедупликации нет) + бессмысленная фраза как
  естественный фейл (пустая динамика → fail-closed). Одна сессия на все фразы;
  фейл одной фразы не останавливает батч; `--region` применяется один раз
  (первая фраза). Код выхода 1 при наличии фейла.
- **B8. phrases-file в cp1251**: декодируется fallback-ом, собирается.
- **B9. `--output-dir`**: структура `runs/<...>` создаётся в указанном корне.
- **B10. `--strict-exit`**: живой прогон даёт exit 2 (пустые top-виды делают
  результат частичным всегда).

## C. Дозапись (`--resume-dir`)

- **C1.** Удалить из собранного каталога один `<view>.parquet`, запустить с
  `--resume-dir` той же фразой/регионом: пересобирается только он;
  `created_at` не меняется, `updated_at` растёт, `source_url` обновляется,
  mtime остальных parquet не тронуты.
- **C2.** Полностью собранный каталог: ранний возврат — байты `manifest.json`
  не меняются (сравнить sha256 до/после), exit 0.
- **C3.** Другая фраза: pre-flight отказ `does not match`, exit 1, браузер
  не стартует.
- **C4.** Другая гранулярность/период: Chrome стартует, фраза падает с
  `different dynamics granularity or requested period`, exit 1 (pre-flight
  это НЕ проверяет — только collector).
- **C5.** Каталог без `manifest.json` → `No manifest.json found`; с битым
  JSON → `not a valid Wordstat manifest`.

## D. Разрушительный (по желанию, в конце)

- **D1.** Убить сессию командой `wordstat logout` (удаляет только Yandex-куки;
  клик «Выйти» ненадёжен — при нескольких аккаунтах Яндекса он уводит на
  страницу выбора аккаунтов и сессия выживает) → батч из 2 фраз: единственная
  строка
  `Error: Wordstat requires an authenticated Yandex session in the attached
  Chrome`, exit 1, stdout пуст, run-каталоги не создаются. Это fail-fast до
  цикла фраз (`_collect_batch_phrases` проверяет авторизацию до первой
  фразы); суффикс `батч прерван, N фраз(ы) не пробовались` возникает только
  при смерти сессии посреди батча — живым прогоном недостижимо, покрыто
  юнит-тестом. Восстановление: `wordstat login --check` (exit 1) →
  `wordstat login` (перенос сессии из повседневного Chrome; один Keychain-промпт)
  → `wordstat login --check` (exit 0), затем контрольный прогон `collect`.

## Известные особенности живого Wordstat (не ошибки инструмента)

1. **top_popular/top_related всегда 0 строк** (issue #22): прогон штатно
   частичный; `--strict-exit` на живом прогоне всегда даёт exit 2.
2. **Лаг финализации данных у present-края**: последняя единица запрошенного
   окна может отсутствовать (день/неделя/месяц). Контейнмент-проверка
   принимает укороченный ряд; исторические окна возвращаются ровно.
3. **Weekly-окно применяется** (живое подтверждение 01.09.2026; пометка
   «Wordstat игнорирует даты для weekly» в README устарела — 21.08 и 01.09
   дали разные исходы, при повторении проверить ещё раз).

## Что живым прогоном не проверяется

Разлогин посреди батча, убежавшая/двойная загрузка CSV, `PhraseEntryError`
(React race), сбои `session.stop()`, поломка селекторов Wordstat — покрыто
юнит-тестами или недетерминировано; живой прогон проверяет лишь отсутствие
`InterfaceChangedError`.
